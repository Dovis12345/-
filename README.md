# 巷陌留痕｜泮塘五约民间记忆数字地图

这是一个无需构建工具的静态交互网站原型，用于展示广州泮塘五约的居民口述、田野日志和艺术转译成果。

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 页面内容

- 首页叙事与项目数据概览
- 七个记忆点位的叙事地图
- 空间、民俗、生活、情感四类筛选
- 点位详情抽屉：居民原话、访谈问题、主题编码、录音、艺术作品
- 田野日志和证据链
- 点位冰箱贴、民居插画、水生五秀 IP 等艺术转译
- 桌面端地图与移动端纵向路线适配

`assets/` 中的图片和录音来自本次提供的作品集、访谈录音和访谈日志。旧网页点位图没有用于视觉设计。
